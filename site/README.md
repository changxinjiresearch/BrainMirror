# BrainMirror — Interactive Web Foundation v0.3

This is a static, fully browser-run **trace explorer**. It is NOT a medical data interface or real-time PyTorch inference. All graphs derive from `trace.json` generated by a real PyTorch model trained on **synthetic, non-human voxel phantoms** (8 samples, 3 epochs).

## Features
- 3D rotatable sampled synthetic input point cloud (650 true recorded coordinates).
- 512 real `conv3` tensor elements with baseline and perturbation differences.
- Browse six recorded real PyTorch forward runs (0-2.5 voxel perturbations); no interpolated or fabricated activations.
- Click a node and view six measured activations; actual 216 input weights and values for only one saved node (`conv3[0,2,2,2]`).
- Plot weighted contributions and display the effect measured by the source script. Numbers in the stored trace are rounded, so their recomputed sum need not match the unrounded original preactivation exactly.
- Local export of experimental records. No telemetry, cookies, or MRI upload.

## Limitations
- MRI dataset `IXI` has been mounted and subject-file count inspected by researcher, **but its images have not been processed and are not bundled here**.
- This site does not send requests to a model backend. Changing the slider selects one of six prerecorded runs.
- Schematic ROI marker is a visual reference only; source trace did not preserve full ROI geometry.
- Displayed 3D node positions are indices, not anatomy. No false cross-unit network edges.
- Mechanistic validation and healthy brain learning: NOT STARTED.

## Running
```
python -m http.server 8080 --directory site
```
Open http://localhost:8080. Deploy `site/` as a static website. The site does not access the Kaggle private dataset or any medical image.

## Source
`trace.json` is copied unchanged from the previously generated `BrainMirror-v0.2-web/full_512_unit_trace.json` (source script `reproduce_trace.py`), to preserve the original numerical record. No values are invented at runtime.
