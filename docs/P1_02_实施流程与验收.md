# BrainMirror P1 — 可执行数据准备 SOP 与验收条件

## 科学边界

- P1 仅做正常脑 MRI 来源资格、元数据、QC、受试者级划分与预处理准备。**不得提前训练 AI**。
- P0 的 32³ synthetic phantom 和本地 PyTorch 观察原型不可与真实人体 MRI 结果混算。
- 任何导出的匿名聚合数据都必须有人独立审查后才允许公开。

## P1.1 数据取得与私有存储

1. 在 IXI 官网阅读原数据说明、下载页与 CC BY-SA 3.0 条款。
2. 仅从官方网站或官方指定来源取得 T1 NIfTI；建议保留官方包压缩格式并核对 SHA256。
3. 在私有、具持久性的 MRI 数据目录解压。数据目录**必须在 Git repo 外部**，示例：`/kaggle/input/ixi-t1`（只读）；结果输出目录也在仓库外部，例如 `/kaggle/working/brainmirror-private-p1`。
4. 不要将患者图像、扫描文件名、原始 ZIP、可识别元数据或 Token 复制进 GitHub。
5. 不下载尚未核实来源/许可的数据。

## P1.2 预检运行

Python 3.11+，安装 `numpy`, `nibabel`, `pytest`。受限执行环境中若缺少 `nibabel`，请先在具备该依赖的环境安装并运行；不能把 fixture 测试当真实 MRI QC。

```
# 必须自行设定长度 >=32 字节的私有 HMAC 密钥，不打印、不提交。
export BRAINMIRROR_P1_HMAC_KEY='<operator-created-secret-of-at-least-32-bytes>'

python scripts/p1_intake.py \
  --data-dir /private/ixi-t1 \
  --output-dir /private/brainmirror-p1-audit \
  --accept-ixi-terms \
  --voxel-qc
```

输出写入私有目录：

- `private_scans.json`：各个扫描的相对路径、**HMAC 标识**、原始文件 SHA256、NIfTI 元数据、QC 原因和待审核 split。
- `aggregate_receipt.json`：仅含总数、失败原因分布、各 split 受试者数量及阶段门禁，不含任何逐人标识。

**操作提醒**：`--accept-ixi-terms` 只能在真正看过条款且有权使用该数据后添加。`--voxel-qc` 会真实读入体素并检测有限值/近空图像；不加时仅查头信息。

## P1.3 QA 门禁（机器 + 人工）

1. `DATA_SOURCE_VALID`：有来源网址、许可、取得日期与独立 SHA/清单。
2. `SUBJECT_ID_CONFIRMED`：源内受试者标识可可靠解析；不能解析则整份扫描隔离。
3. `HEADER_PASS`：单一 3D MRI、合理尺寸与 spacing、有限非退化 affine、qform/sform 一致或只有一个有效定义。
4. `VOXEL_QC_PASS`：输入非空、无 NaN/Inf，有合理前景比例；人工 review 异常方向、畸变、覆盖范围和伪影。
5. `DUPLICATE_GATE`：文件同 hash 但不同 subject ID 会触发拒绝；真实跨模态/跨数据集近重复需额外策略，当前代码**未完成**影像相似性去重。
6. `SPLIT_CANDIDATE`：同一 subject 的多次采集不能进入不同 split；只有完整私有 cohort 通过 QC 后才允许人工批准和锁定。分配结果是草案，**不是锁定结果**。
7. `PREPROCESS_VALIDATION`：RAS、bias correction、brain extraction、re-spacing 等预处理应在后续任务实现，并用体素级/解剖级回归测试验证，不允许跳过。
8. `PUBLIC_RELEASE_GATE`：只允许经人工检查的匿名汇总统计入公开 Git，任何逐人 manifest 留在私有位置。
