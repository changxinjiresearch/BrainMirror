# BrainMirror SCEPT · SCCA v0.4 工程规范与验证回执

**日期：** 2026-10-16  
**研发分支：** `phase/scept-transformer-vib-alpha-20261016`  
**状态：** 合成数据数值正确性工程原型；**非** BraTS2020 / Grad-CAM 科学有效性证明。

## 一、这一版的真正改变

v0.3 可将早期残差分支的变化传播到后续 Transformer 层的 Q/K/V **整个输入**，而非特定 Attention Head/Token-to-Token 运算。v0.4 增加独立的真实矩阵算法与受控干预，能明确区分：

1. **加权 Value 消息**：对固定批次、head `h`、query `q`、key `k`，定义 `M_{hqk} = softmax(QKᵀ/√d)_{hqk} · V_{hk}`。将这一条 *post-softmax message* 的参考值替换为另一输入的该项，并经当前 head 对应的 `W_o` 投影注入到 `attn_to_residual` 的 **单一 Query 输出 token**。所有其他位置和 head 的消息保持参考状态。这是明确的计算干预，**不是**改变输入图像或真实注意力参数的反事实。
2. **单一 QK Logit**：只将对应未归一化 score 替换，重新对整个 Query 行执行 Softmax；因此其他 key 的权重会联动改变。不能把这称为“只有一条注意力边受影响”。
3. **真实算子复核**：手写 `Q/K/V → Softmax → AV → W_o` 分解与 PyTorch `nn.MultiheadAttention` 的实际输出和 head 权重进行逐元素比较。支持当前 `batch_first=True`、dropout=0、无 mask/bias_kv 的 self-attention。遇到未验证的变体直接拒绝。
4. **跨层原子回路**：按前层残差分支 → 指定 Head 的单条消息 → 后层 MLP 的有序路径传播，每跳计算只通过选中分支，其余中间残差分支冻结为参考值。只允许终点为最后一个 MLP gate，保证终点下游没有其他 Transformer residual 分支，之后自然运行最后 norm、Spatial VIB 和真实 Decoder。可以在终点进一步只恢复一个 `z[token,channel]`，观察它的下游影响。
5. **独立 Spatial VIB/Decoder 核验**：固定参考 `z`，仅替换单个空间潜在 token 的特定维度，经过真实 `ConvTranspose3d` Decoder 重算，另外用 `conv_transpose3d(delta_z, weight, bias=None)` 检验输出变化。该检查是精确的线性卷积转置恒等式，不是模拟的因果热力图。
6. **两级 3D Transformer**：独立原型采用 `3D Patch Embedding → Fine Transformer → 2×Patch Merge → Coarse Transformer → Spatial VIB → Latent Upsample → Fine Skip Fusion → 3D Decoder`。可追踪细尺度网格坐标到粗尺度坐标 `floor(z/2),floor(y/2),floor(x/2)`，仅替换一个细尺度 token 对目标 Patch Merge 单元的贡献，而保持独立细尺度 Skip 为参考状态。
7. **多尺度原子路径**：在合并单元受控变化后，进一步挑选粗尺度 Transformer 的指定 head/query/key，**只**注入对应的加权 Value 消息或 QK score 的变化；未选择的粗尺度 Attention 输出、直接 merge→residual 旁路、细尺度 Skip 仍使用参考输入，之后由真实 MLP、Spatial VIB 和 Decoder 重新计算。v0.4 此模式限制粗尺度 Transformer 为一层。
8. **有界候选搜索**：明确传入 head / query / key 候选，最多运行 `max_tested` 次，每次记录符号、输入评分效应、单路径恢复效应与归一化误差，不会将筛选结果称为患者级独立验证或发现完整回路。

## 二、计算语义不可混淆

| 操作 | 计算意义 | 不能声称 |
|---|---|---|
| `weighted_value` | 替换一个已经 Softmax 加权的 `A[h,q,k]·V[h,k]` 消息，其他消息冻结 | 改写 Q/K 后全部自然计算也只影响一条消息 |
| `logit` | 在特定 head/query/key 处替换一个 pre-Softmax 分数，再重新归一化该 query 行 | 其余键的注意力权重不变 |
| 跨层原子路径 | 仅沿定义的分支和参考残差状态传播增量 | 已找到唯一自然运作的真实脑生物机制 |
| VIB token | 对 `z[token,channel]` 进行输出端干预，真实 Decoder 重算 | KL 即真实互信息，或该 latent 具有已确认医学语义 |
| 多尺度 merge | 单个 fine token 通过真实 merge 的一个 coarse cell | 所有医学空间依赖都只经过该 coarse cell |

### 主要边界

- 本版本仍为**固定 3D crop、全注意力、小样本/小网格 CPU 原型**，不是高分辨率 BraTS/SwinUNETR；最大 token 数有显式限制。
- 低层 Q/K 变化经过 Softmax 会耦合所有 key；对独立 weighted-value 消息的替换是一个外科式数学干预，不等价于真实输入下的局部因果路径。
- 跨层路径允许串联若干明确的分支，但真实模型存在冗余/交互，不能把选中路径当作唯一、完整或语义稳定的模型内部决策机制。
- 在 `MultiScaleTransformerVIB3D` 中，细尺度 skip 绕过了 VIB，必须保留并显示旁路；VIB 不会压缩所有预测信息。
- 多尺度原子模式暂只支持 coarse 层 `0` 且只有一个 coarse block；路径末端的 coarse MLP 是自然传播，尚未对该 MLP 做单独 edge-closed 冻结。
- 在完整医学实验开展之前，**不得**声明 SCEPT 替代或优于 Grad-CAM、具有临床可靠性、完成双模型 I-JEPA 机制科学验证。

## 四、验收与复现

在仓库根目录执行：

```bash
pip install -r requirements.txt pytest
python -m pytest -q tests
python -m scripts.scca_atomic_v04_smoke --output runs/scca_atomic_v04_synthetic_smoke.json
python -m compileall -q brainmirror scripts
```

单头、单消息的数值基线：显式分解的多头输出与原生 PyTorch 输出一致（浮点容差 `atol=2e-6,rtol=2e-5`）；Q/K 置零时单条 logit 差值为零、Value 消息可仍有作用；整个选定 head 的输出投影置零时，消息到残差输出的效应必须为零。

VIB 线性 Decoder 独立 oracle：在固定随机种子 `240216` 的 smoke 中，最大输出差异约 `2.43e-8`（具体精度依赖执行环境）。跨尺度 `fine_to_coarse` 对全部 64 个 fine tokens 与直接整数索引公式逐一对应；无效索引和不匹配输入拒绝执行。

**本地测试：** 55/55（截至本文首次编写；最新完成总数以 CI 测试日志为准）。合成数据中可出现零效果、负效果或路径无显著作用；代码必须诚实返回，不虚构重要性。

## 五、下一批研究瓶颈

1. 对 W-MSA/SW-MSA（窗口/移位窗口）、相对位置偏置、注意力 mask 的真实算子等价与原子化拆解；仅写可视化不算完成。
2. 连接 SCCA 的多尺度回路联合搜索、冻结非目标路径和 cross-scale `Q/K/V` 原子梯度候选评分。
3. 将 Patch Merge / Upsample / 3D Decoder 对应回原始 MRI 物理空间坐标和 NIfTI affine，加入医学影像空间完整性 QC。
4. 梯度和组合效应对照、合成隐藏路径的不可辨识性审计、分布外参考影像风险、独立病例验证。
5. 真正的 3D I-JEPA vs Scratch 预训练/分割实验与基于独立数据集的 Grad-CAM 对照。

本回执确认的是**工程正确性范围内的实现**，不把算法运行、GitHub CI 和新方法的科学有效性混为一谈。
