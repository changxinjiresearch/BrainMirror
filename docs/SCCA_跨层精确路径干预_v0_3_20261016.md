# BrainMirror / SCEPT — SCCA 跨层受控路径干预 v0.3

日期：2026-10-16。**合成数据工程原型，尚非临床解释验证，也未完成 Grad-CAM 对比。**

## 一、这次真正改变了什么

v0.2 的多边联合替换并不能证明 *某条有序跨层路径* 对输出有作用。v0.3 引入 `brainmirror/scept/paths.py`：

1. 从真实的 `blocks.i.attn_to_residual` 或 `blocks.i.mlp_to_residual` Gate 选择源边（模型代码中每个 Gate 只有一个残差消费者）。
2. 对原始输入和参考输入分别运行，保存真正的 Gate 激活以及每个 LayerNorm 之前的原始残差状态。
3. 计算**源边激活差**。沿下一目标分支的残差 identity 传入该差值，**所有未选中分支固定为同一参考运行的数值**；这不是简单重放全模型。
4. 如果下一目标是 Attention：根据路径角色选择只让 Q、K、V 或联合 QKV 接收混合状态，其他输入使用参考状态。实际调用 `nn.MultiheadAttention(q,k,v)` 重新计算后续张量；没有靠 Attention 权重假装是因果边。
5. 如果下一目标是 MLP：只通过真实的 LayerNorm 和 MLP 重新计算输出。每次完成目标分支后，将当前传播差值**替换**为该分支的输出差值，不允许之前源分支的未选旁路继续混入下一跳。
6. 在**最后一个 Gate** 注入该路径的重新计算状态；此后模型按正常前向传播，得到真实输出变化。反向使用 clean/ref 交换再做一次，分别报告破坏、恢复效应。
7. 自动搜索候选二跳/三跳及更长受限路径，先用梯度做排序，然后每条路径实测，按 SCCA 联合目标排序；**第二种参考只用于冻结选中路径后的复核**，禁止用于挑选路径。

## 二、路径定义与精确性边界

对于一条 `s -> t1 -> t2`，语义是“选定源分支的 clean-ref 差，仅通过指定残差恒等桥和 t1 分支重计算，再仅通过指定残差恒等桥和 t2 分支重计算，最后在 t2 的分支加法 Gate 注入，观察输出效应”。

这是**在声明的计算子图及冻结非路径计算条件下可数值检验的路径特定干预**；不是模型原始推理时唯一活跃路径，也不等于全网络的全部路径总效应。

* 真实：Gate、LayerNorm、Q/K/V 输入、Attention 核心、MLP、Decoder 均来自当前实际 PyTorch 模型与参数。
* 精确：在固定确定性 `sample=False`、明确的冻结约定下，路径重计算使用真实参数且可通过手工代数 oracle 验证。
* 限制：尚无逐 Head 独立干预、Attention token→token 的原子边隔离、Swin 窗口注意力、Patch Merging 跨尺度路由、Skip Connection 子路径追踪；不能据此宣称完整多层因果回路已发现。
* 边界：输入参考是合成的 `channel_mean` / `local_blur`，并非医学上合理的患者反事实；独立患者验证和统计泛化未完成。
* 注意：`QKV` 表示多输入联合条件，不应称为一条原子 Q 或 K 边。

## 三、实验与工程质量

- 独立构造的参考运算验证：干预引擎给出的 target-MLP Delta 与手工计算 `MLP(LN(ref_preMLP + source_delta)) - ref_MLP` 一致。
- 真实 Attention Q、K、V 角色对照：分别替换一个输入源后，匹配独立调用 `MultiheadAttention` 的输出，且 Q/V 得到不同结果。
- 三跳传播：选定中间 Attention-Q 分支路径后，最后一跳结果等于逐步显式重计算，并且与不经中间 Attention 的快捷旁路不同。
- 零差值 / 空 token mask：预测严格无变化，禁止浮点重计算噪声被误报为真实效应。
- 非法路径（逆序、未知边、非法 Q/K/V、无效形状）必须拒绝；Hooks 必须全部清理；权重和梯度不改变。
- 自动候选搜索受 `max_candidates / max_hops / max_tested_paths` 约束；结果保存所有实测路径及未通过状态；独立参考策略复验不冒充患者独立性。
- CI 运行完整测试集 `python -m pytest -q tests`；脚本 `python -m scripts.scca_path_smoke --output runs/scca_cross_layer_smoke.json` 输出真实数值的合成实验记录。

## 四、下一版必要工作

1. 专门实现 Attention **per-head** 和 token→token 消费边的原子干预，并构建具有已知可识别电路的合成 ground-truth oracle。
2. 实现多尺度 Transformer 与空间 VIB token/Decoder skip 的跨尺度路由，并处理 residual 之外的 skip connection。
3. 增加真实 MRI 合理反事实生成、参考敏感性对照、外部病例及 Grad-CAM 公平比较。
4. 优化大规模路径搜索（缓存、批量干预、预设运行预算）与统计不确定性。

当前代码版本 **v0.3 engineering alpha**，不能宣称完成 SCEPT 方法的科学有效性证明。
