# SCEPT v0.9 — BraTS2020 真实医学验证管线与研究证据状态

**日期：2026-10-16；状态：工程管线已实现，BraTS2020 患者级科学验证未完成。**

## 数据来源和验证边界

- BraTS2020 官方标签：0 非肿瘤、1 NCR/NET、2 edema、4 enhancing。三重交叠标签 `WT={1,2,4}`、`TC={1,4}`、`ET={4}`。不同于四类 Softmax，本项目输出为三独立 Sigmoid logits，使用 BCE + soft Dice。评估时分开计三标签 Dice。
- 官方 2020 **有标签训练集为 369 例**；官方提供的 challenge validation 不含公开真值，不得当作可本地计算 Dice 的测试集。对 369 例训练集一次性锁定患者级 70/15/15（258/55/56）划分，并禁止对最后 56 例进行模型训练或调参。此处 test 意味着我们私有拆分的 held-out testing subset，不是 BraTS 官方挑战测试集。
- 已核验其他用户科研仓库 `glioma-xai-evidence` 保留独立 BraTS2020 历史审计：`training_cases=369`、`grade_counts={HGG:293,LGG:76}`、压缩包 `sha256=aa41bd3caf4056e8e85661743b549689826a19244794abf9f9ca45d2384a2cc6`。这些**仅是历史证据**：当前 v0.9 环境未访问该归档原始 MRI。`BraTS20_Training_355` 允许经历史审计已知的 `_segm` 分割文件名，但若 `_seg` 和 `_segm` 共存则拒绝以避免歧义。
- 只有具合法访问权的本地 NIfTI 数据方可运行。代码不能、也不会从公共仓库下载、伪造或提交医学数据。注册、许可、引用依官方 CBICA 文档。
- 当前仓库内尚无经过病例训练的 v0.9 SwinUNETR 模型权重。既有 v0.8 的官方 MONAI 运行均为未训练模型与合成输入，不构成科学有效性证据。

## 冻结实验设计

**P0: 数据 QA 与完整性**

1. 从 NIfTI 原始格式读取同一病例的四模态 + GT 标签，拒绝缺模态、重复、体积 shape 不同、affine 不一致、非有限值和非法标签。
2. 对每通道脑内非零组织做 z 标准化和 ±5 标准差截断，保持背景为 0；记录截断比例、每类肿瘤体素数及 affine 指纹。
3. `prepare` 生成只含 ID、划分、数据目录尺寸指纹的无图像 manifest。严格要求 369 例，除非明确指定非正式工程测试。每例所有模态属于同一固定划分。清单指纹不是 MRI 内容的完整哈希，不能将其误称为数据字节完整性证明。

**P1: 训练（待执行）**

- 官方 MONAI 1.5.1 SwinUNETR 4→3，原型默认 `feature_size=12, depths=(2,2,2,2), heads=(3,6,12,24)`、window=7。每次运行固定架构、种子、优化器、epoch、patch size 和 split SHA，训练只读 `train` 受试者；`validation` 用于模型选择。已有最小训练 CLI 提供基础 AdamW/BCE+softDice，但尚未实现完整早停、独立调参和多随机种子成熟实验，请勿当作终版训练策略。
- 训练结束将模型权重保存在 **私有执行环境**，公开仓库只允许保存 SHA-256、脚本、配置和去身份化结果，不提交 `.pt/.pth/.nii/.nii.gz` 文件。
- 拒绝无训练步数、无来源、monai 版本不兼容、train IDs 与冻结划分不符、test 数据泄漏或 checksum 不符的模型；注意自报 metadata 无法替代独立训练日志审计。

**P2: 患者级独立分割评估（待执行）**

- 对冻结的 held-out 56 例，以 MONAI `sliding_window_inference` 按 96³ 窗口、25% overlap 执行分块推理；逐病人 WT/TC/ET Dice。真值为空且预测亦为空时报告 null/undefined，不虚增 Dice。
- 保存逐病人 Dice 和各区体素数，汇总病人级宏平均；目前没有任何真实患者的 Dice 数字。正式统计还需置信区间、HD95、失败病例审计和至少多种子复验。
- 进入 SCCA 机制研究的预先声明质量门槛：完整独立评估至少 10 人，并且 WT≥0.65、TC≥0.45、ET≥0.35（**启发式工程准入阈值**，不是行业公认临床验收标准）。不满足时拒绝声称存在可解释的高质量模型。

**P3: 局部 ROI 的 SCCA 第一轮机制测试（待执行）**

- 在测试病例中用人工标注界定 WT/TC/ET ROI 用于研究分析。GT 掩码来自 test 标签，仅用于解释目标界定，不可泄漏进预测输入。
- 统一定位 默认 64³ 对齐局部 patch（32³ 仅允许特殊无 InstanceNorm 工程测试），从原始 MRI ROI 构建两种参考：脑内非目标区域中位强度（不保证医学上为正常组织），以及仅在 ROI 内应用局部平均模糊。两者是**诊断性干预**，不是经医学影像专家认证的真实反事实或分布内合成。测量 ROI 内改变幅度、ROI 外精确零改变，记录 OOD 风险。
- 调用 v0.8 `discover_monai_crosslayer` 在官方模型上寻找有界的受控原子级路径。每条候选保存干预效应、负控 `cut_at_last`、跨参考方向一致性、搜索预算及 `Unresolved/Conflicting`。参考变化一致≠独立病人泛化。
- 当前 v0.9 的 SCCA 评分只在**单个局部 patch 的独立前向**下定义，不等价于滑窗拼接的全 MRI 预测或完整 BraTS 队列预测因果效应。不能把局部结果直接声称为全脑尺度因果解释。

**P4: 正式科学有效性（v1.0 前必须完成）**

- 至少 BraTS2020 患者级 holdout 的多案例研究、多个随机种子、标准误/置信区间；Grad-CAM、Integrated Gradients、Occlusion、公平计算预算与共同 ROI 输出目标；捷径、置零/负控、消融、双向因果效应；预训练 vs from-scratch 的相同主干网络、相同训练设置对照。
- 相同测试病例不得在观察初步结果后选择性筛掉；任何门槛、ROI 规则、类目、参考与统计必须预先登记。

## 代码执行（含实际前置条件）

```bash
pip install 'torch>=2.3,<3' 'monai==1.5.1' 'einops>=0.7,<1' 'nibabel>=5.3,<6' numpy scipy
# 以下 --root 为示意性已有授权本地路径；脚本不会下载数据
PYTHONPATH=. python scripts/scept_brats_v09.py prepare --root /path/to/BraTS2020_TrainingData \
  --output runs/brats_v09_split.json
PYTHONPATH=. python scripts/scept_brats_v09.py train --root /path/to/BraTS2020_TrainingData \
  --split runs/brats_v09_split.json --checkpoint /private/scept_v09.pt \
  --output /private/scept_v09_train.json --device cuda --epochs 30 --patch-size 96
PYTHONPATH=. python scripts/scept_brats_v09.py evaluate --root /path/to/BraTS2020_TrainingData \
  --split runs/brats_v09_split.json --checkpoint /private/scept_v09.pt \
  --checkpoint-sha256 <verified_sha256> --output /private/scept_v09_eval.json --device cuda
PYTHONPATH=. python scripts/scept_brats_v09.py explain --root /path/to/BraTS2020_TrainingData \
  --split runs/brats_v09_split.json --checkpoint /private/scept_v09.pt \
  --checkpoint-sha256 <verified_sha256> --evaluation-report /private/scept_v09_eval.json \
  --case-id BraTS20_Training_001 --region WT --output /private/scept_v09_scca.json --device cuda
```

注意 `explain` 的 case-id 必须属于预先锁定的 test split；示例 `001` 仅展示参数格式。实际工作必须通过前一环的评估门槛，`--checkpoint-sha256` 禁止省略。训练与正式病例推理需要足够 GPU；云端 CI 只执行 32³ 合成 NIfTI + 官方 MONAI 的工程烟雾验收。
