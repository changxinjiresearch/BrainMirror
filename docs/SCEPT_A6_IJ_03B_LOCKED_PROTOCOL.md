## Critical limitations

- This is frozen **validation** data, potentially used to choose original checkpoints, not a new independent clinical test.
- SCEPT numeric distances/CKA correlate with gradients only descriptively. A significant rho, or improvement over a baseline in subsequent 03C, does not establish medically faithful explanation.
- Ten slices within a patient **are not ten statistically independent people**; bootstrap is clustered by patient.
- Risk management: Kaggle CPU/GPU quotas and private GitHub Release upload limits may affect runtime. Do not make unsupported time/cost guarantees. Chunk and pilot are mandatory to measure runtime and preserve data.
- Complete original patient-derived internal tensors, identifiers, input SHA hashes stay private. Public BrainMirror contains executable algorithms and documented non-sensitive protocol only.
