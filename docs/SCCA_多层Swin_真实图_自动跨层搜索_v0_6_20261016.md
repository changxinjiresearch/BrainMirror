# BrainMirror · SCEPT / SCCA v0.6

## 可执行 3D Swin 风格计算图与自动跨层原子回路搜索

**2026-10-16 | 工程 Alpha | 合成数据，不是医学或临床证据**

### 1. 本轮定义

v0.5 是两尺度、单 coarse Block 的全局自注意力模型。v0.6 新增独立的 `MultiLayerSwinVIB3D` 可执行适配层：

- 两尺度 3D Patch Embedding / Patch Merging；每尺度至少两个 Transformer Block。
- 常规窗口注意力（W-MSA）与循环移位 + 严格边界掩码（SW-MSA）交替。
- 捕获每层真实 Q、K、V、QK logits、掩码、Softmax、加权 Value、输出投影、残差路径、MLP；保存每个窗口里的**全局 token ID**，不是人为视觉布局。
- Spatial VIB（在因果路径实验中取确定性的 `mu`）、Decoder，以及**绕过 VIB 的 fine skip**。
- 真正参与前向运算的索引与掩码同时用于 `execution_topology` 生成可审计拓扑：不是仅画一个看起来像 Swin 的示意图。
- 不依赖手动指定 Head、Query、Key 或层序列：使用 source MRI ROI 的实际输入干预自动筛选 embedding token，以梯度近似筛选每一层的合法窗口原子交互，带预算 Beam Search，再执行双向精准路径干预和第二参考复核。

**重要限定：** 此代码是我们自行实现的 **3D Swin 风格、两尺度、多 Block 研究适配模型**。它不是官方 MONAI `SwinUNETR`，不能未经适配就直接加载 SwinUNETR 权重；窗口数、尺度数与具体架构仍比正式 SwinUNETR 简单。它没有经过 BraTS2020 训练。

### 2. 真实运算与窗口拓扑

`WindowAttention3D` 的计算为：

```
3D tokens -> [shift(-s)] -> window_partition
-> Q/K/V projections -> masked QK / sqrt(head_dim)
-> softmax -> attention weighted values -> output projection
-> window_reverse -> [shift(+s)]
```

遮罩执行标准移位窗口的分段区域规则，防止循环滚动把远距离边界强行相连。`token_ids` 是实际展平空间位置，不是新的虚构节点。每一个合法 Q→K 对均可由 `allowed[window, q, k]` 审计。被掩码禁止的配对会在原子干预中立即抛错。相同参数和输入下，记录模式与普通推理输出完全一致。

局限：要求各尺度空间维度可被窗口大小整除；未实现 SwinUNETR 任意裁剪的填充、relative position bias、dropout、stochastic depth、不同 stage channel width 或额外深度的外部架构权重。不可将以上部分隐含为已通过适配。

### 3. 有严格定义的跨层路径

给定基准 MRI `X_ref`、供体 `X_clean` 和 MRI ROI：

1. 仅从 ROI 造成改变的 Patch Embedding token 中自动挑选若干候选。此时 patch 卷积非重叠，token 与输入 patch 的对应关系可追溯。
2. 从参考模型的 fine Block 0 开始，仅以一个源 token 的差分构造混合输入。
3. 在每一个后续 Transformer Block 中，仅根据一个候选的 **Head + Query + Key** 更新指定 Attention 原子消息；不传播未选中的注意力、MLP、直接残差旁路输出差分。该原子可以是：
   - `weighted_value`：单个 post-Softmax `A[h,q,k] * V[h,k]` 消息替换；
   - `logit`：替换单个 pre-Softmax QK score，重新归一化整条 Query 注意力行，保留基准 V。
4. 将指定 fine 输出经 LayerNorm 及实际 `2×2×2 Conv3d(stride=2)` Patch Merging 传到唯一受影响 coarse 位置；未选中的 coarse 位置必须完全不变。
5. 以同样规则从 coarse Block 0 穿过 coarse Block 1。
6. 将最终隔离的差分送入 coarse LayerNorm / Spatial VIB `mu` / 转置卷积上采样 / Decoder；**fine skip 始终来自当前参考运行**，不得泄漏供体状态。

这是一套精确定义的 **人为计算路径干预**，不是证明人脑病理因果关系，更不是声称找到了 Transformer 唯一、天然的解释路径。当前路径语言要求每个 Block 有一个选定 Attention Atom，不覆盖纯 MLP 路由、直通 residual route、复杂多路径协同或 VIB 内的全部随机效应。

### 4. 自动搜索与算法预算

- 用参考路径上的 `∇ output_score / ∇ attention_branch` 作为**筛选近似**；这不是因果效应。
- 针对每层当前状态，计算真实混合 Q/K/V，枚举当前窗口允许的两个原子模式。
- 把每个候选原子的实际输出差分投影回真实 residual channel，选出规定数量的 Beam；若零效应或搜索无解则返回 `unresolved`。
- 只在完整路径拼接后，执行完整的**双向路径干预**（破坏 + 恢复），使用固定目标分割 ROI 的 logit 评分和 off-target 惩罚排序。
- 候选选择完成后才使用第二种参考影像复验；**同一合成病例、两种参考**不能当作患者级外部验证。
- 预算参数：`beam_width`、`max_source_tokens`、`per_state_proposals`、`max_exact_paths`、`validate_top`。候选计数包括筛选过的合法原子交互，但不是等量的完整模型运行次数。

### 5. 正确性验证

`tests/test_scca_swin_v06.py` 包含以下核心正反控制：

1. 普通 W-MSA / shifted SW-MSA 同独立 PyTorch `scaled_dot_product_attention` 双精度计算一致。
2. 跨普通窗口的真实邻接可通行；被循环移位制造出的伪边必须被拒绝。
3. 模型的捕获模式不改变正常推理；梯度能够传到 Embedding、Attention 和 VIB。
4. 单 Head/Query/Key weighted Value 与 QK-logit 的差分同逐项独立代数计算一致。
5. 供体与参考完全一致时，路径干预不能凭空改变预测。
6. 路径顺序、窗口索引或 token 越界必须失败，不得自动“修复”成假路径。
7. ROI→单个 Patch Merging 区块映射精确；fine skip 在跨层干预中保持参考张量逐位一致。
8. 内部 `execution_topology` 的 Q/K 对应与执行时实际 mask/token IDs 一致。
9. 把第一层 Attention 输出投影整体置零后，搜索**不得生成非零机制回路**，即使其他残差/skip 仍能影响最终预测。
10. 已知均匀 Attention 的单 Value 消息，输出差分精确等于供体差分的 `1/8`；Q/K 投影为零时 QK-logit 变化为零。
11. 随机种子、输入、权重固定时搜索可重复，结果完全 JSON 可序列化。

整个现有回归集应在 CI 运行；局部测试只是工程验收，不是论文验证。

### 6. 如何重现实验

```bash
python -m pip install -r requirements.txt pytest
python -m pytest -q tests
python scripts/scca_swin_v06_smoke.py --output runs/scca_swin_v06_synthetic.json
```

示例输入是固定种子的**人工三维张量**，没有受试者，没有 BraTS2020，不需要下载数据。实验 JSON 保存路径、预算、真实效应、版本、哈希和解释状态。模型没有训练，因此自动搜索可能返回未解决/冲突，这是预期且须如实披露的结果。

### 7. 后续必须完成但不属于本次验收

- 真实 MONAI SwinUNETR / Swin3D 权重、任意窗口 padding、shift mask、relative-position bias、各层宽度、移位窗口连接的**权重兼容适配**和 API 接入。
- 支持所有注意力、MLP、残差、skip 组合的广义跨层回路搜索及组合干预，而非“一层一个 Attention Atom”的有限路径语言。
- 对实际 BraTS2020、有效医学反事实和 I-JEPA 与 scratch 模型进行配对训练与解释，患者级锁定数据、统计置信区间与 Grad-CAM 等强基线。
- 结果可扩展性：多 GPU、真实体积分辨率、内存预算、预存 trace 与可校准的可靠性指标。

**科学状态：** v0.6 证明的是受控执行路径计算与搜索的工程正确性；未证明医学机制有效性、路径唯一性、与 Grad-CAM 比较优势或 SCEPT 独立学术新颖性。
