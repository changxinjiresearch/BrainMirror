# SCEPT / SCCA v0.5 — 自动化多尺度候选机制发现

**状态：可执行工程原型，合成数据验证。不是医学解释真实性或论文新颖性的证明。**

## 1. 本轮突破

输入只有三维 MRI-like tensor `[1,4,D,H,W]`、选中的 MRI 布尔掩膜和可选的固定预测目标区域。**无需人工给定 fine token、Attention Head、Query、Key 或路径**。系统自动：

1. 仅在选中输入区域施加诊断性局部模糊，记录与原始 MRI 的真实输出差值。
2. 通过模型可执行计算图捕获 fine 特征、`patch_merge` 输出、coarse Attention 残差输入和分支张量。
3. 用**仅经过 Patch Merging 分支**的梯度 × clean/reference 特征差分筛选 fine-scale 中介 token。专门排除了 fine skip 对来源筛选梯度的污染。
4. 对候选 fine token 逐一进行真实 `patch_merge` 差分计算，严格验证只有一个 coarse cell 受到影响；细尺度局部空间坐标转换为粗尺度网格索引。
5. 依据 Attention 原始 Q/K/V、Softmax 与 `out_proj` **真实参数**，计算每个 `(Head, Query, Key, mode)` 的一阶输出目标代理分数。`weighted_value` 是单个加权 Value 消息；`logit` 更改单个 QK 分数，允许 Softmax 行耦合。
6. 全局候选排序后，限制真实干预最多执行 `max_exact_tests` 次；对每个候选在参考上下文测**恢复效应**，在原始上下文测**破坏效应**，并给出非目标区变化。
7. 在候选筛选**完全结束以后**，使用预留的另一种参考（选中区域外的每模态均值）复测部分候选。不能用这个参考反过来挑选首轮候选。
8. 结果按实际效应报告 `best / candidates / reserved_validation / status`，并保留方向、分数、跳过原因和科学边界。零信号、零 Attention 输出或不一致结果必须拒绝给出有支持的解释。

## 3. 解释边界

- **并非真实的局部输入→token 因果路径**：被选中 ROI 的干预经过 fine 全局 Attention 后，可以改变远处 token。因此这份证据叫 `region-conditioned globally mixed fine mediator`。报告有 `direct_overlap` 标签，但不把其当作因果来源证明。
- **不是普适多层 Swin 机制发现**：现有适配器为两尺度全局 Attention，且只有 **1 个 coarse block**。在该限定计算图上，自动寻找的路径是 `fine mediator → patch merge → coarse atomic message → Spatial VIB → Decoder`；fine skip 在此计算中固定为参考状态。多 coarse-block、Swin 窗口/移位及 head 间组合交互仍需独立适配。
- 诊断性 blur / outside_mean **不保证医学合理性**。两个策略只是同病例的参考敏感性检查，不构成独立受试者、真实病理反事实或跨中心验证。
- `same_case_cross_reference_supported` 仅表示两种诊断性参考下，定义明确的路径干预效果方向得到支持并超过配置阈值。**不是正确解释概率，也不是 XAI 超越 Grad-CAM 的证明。**
- 搜索得到的是有限预算下的**候选原子路径**，不是唯一、最优、完整的天然因果回路；未找到不等于没有机制。
- 目前默认确定性 VIB (`z=mu`)，未声称随机 VIB 多次采样鲁棒性。
