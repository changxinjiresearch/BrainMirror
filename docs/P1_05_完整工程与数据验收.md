# BrainMirror P1 — 数据与科研准备实施说明（2026-10-15）

## 严格状态

- `P1_ENGINEERING_IMPLEMENTED = PARTIAL`（真实图像预处理和去重筛查已实现，但依赖环境未运行真实数据）
- `P1_REAL_DATA_ACQUIRED = FALSE`
- `P1_REAL_QC_COMPLETE = FALSE`
- `P1_SPLIT_LOCKED = FALSE`
- `P1_PASS = FALSE`
- `P2_TRAINING_AUTHORIZED = FALSE`

本阶段的合成数据单元测试、实际 NIfTI 读写测试、模型前向传播测试**不能**替代真实健康人 MRI 的完整数据审计。

## 数据来源与许可

- 唯一主来源：[IXI 官方站点](https://brain-development.org/ixi-dataset/)，伦敦三家中心，近 600 名正常健康受试者的 MRI。
- 官方许可：Creative Commons BY-SA 3.0。研究中须署名和遵守许可。
- 预计需要多个 GB 私有持久存储；下载后保留源 tar SHA256 和相应下载记录。源站若未提供官方公开校验和，不得声称校验值经过官方独立核对。
- 健康受试者是**来源队列描述**，不代表我们已经完成单人影像临床筛选。
- 禁止原始 MRI、面部图像、逐人文件名、密钥或私有扫描表进入 GitHub。

## P1 可执行流程

1. 在具有持久磁盘（建议剩余 ≥10 GiB）、可访问 IXI 官方 URL 的私有计算环境完成官方许可核查。
2. 在 GitHub 仓库之外运行 `python scripts/p1_acquire_ixi.py --private-root /private/IXI --acknowledge-cc-by-sa-3 --extract`。程序会核对 tar 可读性、记录来源 tar SHA，安全解压，拒绝覆盖。`archive_verified` 仍保持 false，待独立来源核对。
3. 设置私有 `BRAINMIRROR_P1_HMAC_KEY`（最少 32 字节，不写入命令记录或 Git），执行：
   `python scripts/p1_intake.py --data-dir /private/IXI/T1 --output-dir /private/BrainMirror-P1-intake --accept-ixi-terms --voxel-qc`
4. 检查 `private_scans.json` 和仅含汇总的 `aggregate_receipt.json`；核实全部扫描与源 tar 一致，处理损坏/多次采集/异常 affine、体素、站点及采集信息。
5. 使用经过独立审计的脑组织 mask（例：SynthStrip 生成并由人工 QC 验证，保留算法版本和来源）；本仓库**不把阈值背景掩膜冒充脑提取**。运行单例验证：
   `python scripts/p1_preprocess.py --image /private/IXI/T1/CASE.nii.gz --brain-mask /private/masks/CASE.nii.gz --output-dir /private/processed --scan-hmac <private_hmac> --mask-provenance 'tool/version+QC source'`
   预处理会检查图像/掩膜 3D 形状、仿射、方位；RAS 化、1.5mm 重采样、mask 最近邻插值、固定 FOV 裁切、mask 质量与脑组织保留比例；在有效脑组织内 robust 归一化，并保存空间与 SHA256 回执。
6. 如适合数据，提供 `--n4` 显式执行 N4（须在私有环境安装 SimpleITK）。N4 未经运行和比对前不可填写质量门槛 PASS。
7. 对全部候选扫描执行 `brainmirror.p1.duplicates.review_candidates` 筛查粗分辨率高相似度样本；**高相似不证明同一人，低相似也不排除重复**，候选必须人工裁决。
8. 审核真实样本包含的个体身份、采集中心、是否多次采集；确保一名受试者仅能归属同一 split。Split 生成器只是 **draft**，需要独立人工批准并锁定 cohort manifest 指纹。
9. 执行 `scripts/p1_closeout.py` 进行 fail-closed 准出，提供 acquisition、preprocessing、duplication、independent review 的私有证据 JSON；任何证据缺失必须输出 `P1_PASS=false`，不允许进入 P2。

## 预处理科学限定

- `bias_correction='none'` 不是自动做过 N4。是否启用 N4 必须预先记录；如 N4 不可用则拒绝执行而非默默跳过。
- 影像空间标签来自有效 affine，不等于病理结构标签。不能用强度阈值自动宣布实现可靠的 skull stripping。
- 脑 mask 源工具版本、原始/输出 affine、resampling 参数、保留比例、输入输出文件 SHA 和抽样人眼 QC 必须保留。
- 预处理期间不产生用于模型评价的 Test 图像统计；所有扫描的空间 QA 可进行，但训练数据才允许用作训练标准化策略估计。当前为**单受试者自身脑组织均值/方差**，不会泄漏跨受试者目标信息。
- Scan 近重复筛查仅生成疑似对照候选，不能代替人工来源审计。

|---|---|---|
| 官方 IXI T1 tar | 已实际取得，来源下载/压缩包 SHA 有独立审查 | 未满足 |

| 受试者级划分 | Train/Dev/Test 人工审核、锁定并备案 | 未满足 |
| 公共仓库检查 | 不含真实医疗影像或个人身份数据 | 自动化检查存在，需持续执行 |
| P1 科学审阅 | 真实数据及完整证据独立审批 | 未满足 |

### GitHub 原则

- `main` 保留已通过审计的工程稳定基线。
- P1 代码在 `phase/p1-data-intake` 分支，Draft PR 供 QA 审查。CI 成功仅代表工程测试通过。
- 审阅通过前不得标记 `P1_PASS`, 不得自动开始 P2 训练。
- 原始 IXI 数据受许可证管理且可含面部可识别影像：私有持久存储，不上传公开源仓库，分发与署名需遵守原始许可。
