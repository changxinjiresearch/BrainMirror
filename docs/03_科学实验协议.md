# BrainMirror 科学协议 v0.1 — 正常脑结构学习与内部计算观测

**状态：DRAFT / 不得宣称科学结论。** 本协议记录待验证假设，首次正式研究前需确定实际健康 MRI 数据、权限、预处理、训练集/验证集/测试集和样本量论证。

## Q0 基础因果链（不预设答案）

健康 MRI `X` → 模型 `f_θ` → 内部计算张量 `z_l` → 重建 `f_θ(X)`。对输入施加有界操作 `T(X)`（保持 θ 不变），比较 `Δz_l=z_l(T(X))−z_l(X)`；随后对内部单元运行 `do(z_l,u := c)`，比较明确的重建输出。空间结构是输入 MRI 中的影像学解剖，不等同于生物大脑电活动。

## H1：解剖表征的出现

**假设**：在不提供显式脑区标签的自监督训练后，模型内部可以产生可被有限复杂度 probe 解码的脑区/形态信息。  
**零假设**：与随机初始化或简单输入纹理特征相比，并无显著改善或增益不能跨人复现。  
**最小指标**：固定 probe 集上，独立下游监督 label 的 linear probe accuracy/MAE/Dice（按任务定义），与 random untrained encoder、像素/卷积随机特征等基线对照。  
**注意**：probe 阳性**不是**语义因果证据，也可能仅证明特征含有可恢复信息。

## H2：结构干预特异性

**假设**：对于经过独立解剖 QC 的某一 ROI 几何变化，存在可重复且不同于匹配强度/非目标区域对照的内部响应模式。  
**零假设**：响应主要由 OOD、强度或整体变形引起，无法区分目标结构改变。  
**指标**：分层内部激活差异、ROI 专一性效应、重建差异、跨受试者复现；报告 target vs non-target、intensity-only、volume-matched、random ROI 的匹配结果。

## H3：指定计算单元参与下游行为

**假设**：在相同 MRI 上置零或 patch 选定内部单元/通道，会对模型的某个**事先声明**的输出指标产生可测量影响，并在多受试者/模型种子上可重复。  
**零假设**：效果不比随机匹配单元显著或高度不稳定。  
**指标**：重建 ROI error change、输出差异、干预选择性、置信区间，以及必要性/充分性候选检验（需配套 rescue/替换对照）。  
**注意**：`ablation-effect != 0` 只支持该干预对某个输出产生局部影响；不直接代表真实生理机制或因果充分性。

## Protocol 1：数据

- **纳入**：经过数据许可审查的真实健康脑 T1 MRI。初期只用单模态，减少混杂。
- **排除**：许可不明、受试者身份不能匿名关联、防泄漏失败、脑覆盖缺失、NIfTI 空间元数据损坏或无法通过预定 QC 的扫描。
- **分割**：受试者级 Train / Dev / Test，可能相同受试者不同扫描必须归属同一集合；种子固定；正式 Test 不参与调参。
- **预处理**：在冻结前定方向/空间/偏场校正/提脑/裁剪/重采样与强度变换；保证所有模型和干预使用相同处理。
- **重点限制**：32³ 仅用于当前合成 debug 的连线与 API 算术验证；由于降采样细节损失，不能用于可靠的海马体等小结构机制结论。

## Protocol 2：模型训练

- Baseline A：仅 MRI 自监督的 3D CNN 自动编码器，目的为可检验和可追踪的基础模型。
- Baseline B：随机权重相同架构，用于区分学习所得响应与架构偶然响应。
- Baseline C（后续）：显式解剖结构监督/约束模型，用于比较不同训练信号。
- 所有模型须记录：seed、optimizer、LR schedule、batch、epoch、precision、package versions、git SHA、checkpoint SHA、split SHA。
- 每个 checkpoint 使用同一套固定 MRI probes，避免时间轴受输入变化污染。

## Protocol 3：图像编辑与对照

1. 选一个 ROI，由合格外部图谱或经审查 mask 指定；不得把这套标签暗中输进无监督训练。
2. 选择 geometry-only deformation，显式记录物理单位、位移场、体积变化率、采样算法；边界体素/重采样像素变化单独报告。
3. 生成 `(X, T(X))` 后，检查非目标区变化、位移 Jacobian、是否折叠、组织连续性、脑外新增信号、强度直方图变化。
4. 与 `identity, non-target ROI, intensity-only, random ROI, volume-matched` 等对照并行。
5. 只在 QC 通过和试验集合按预注册规范合格时使用科学结果，否则仅展示为失败案例，不得进入主统计。

## Protocol 4：真实网络图定义

- Conv3d **原始节点**：`(model_sha, layer, channel, voxel_z, voxel_y, voxel_x)`；所有可见节点能回读实际 tensor。
- Conv3d **输入边**：从前一层对应空间邻域真实计算单元到当前输出单元，属性含 `kernel_index`, `weight`, `source_activation`, `contribution`。padding 零点属于计算常数而非神经元，明确跳过或独立标示。
- **数值校验**：每个被审计输出单元的 `|preactivation - (Σ contribution + bias)| < threshold`；严格与真实前向传播逐层数值一致。
- `latent-distance / correlation / influence` 视图只能在有定义和证据时开放；决不能混用与实际卷积权重相同的连线名称。
- 一个神经元多义、分布式编码、权重对称/神经元置换均是解释结论的潜在威胁。

## Protocol 5：统计与报告

- **实验单位**：受试者，必要时按受试者重采样而非把体素当独立样本。
- **重复**：多个模型初始化和受试者；如涉及多层多单元探索，区分事前确认分析与探索性分析。
- **统计**：给出 effect size、bootstrap 95% CI、负控/正控结果与校正策略；不要仅报漂亮的单例截图。
- **失败标记**：`QC_FAILED`, `UNSUPPORTED_INFERENCE`, `SYNTHETIC_DEBUG`, `POST_HOC_EXPLORATORY`, `NOT_REPRODUCED`。
- **证据等级**：L0 视觉示意；L1 真实数值；L2 相关/统计重复；L3 直接干预影响；L4 复现的局部机制证据。任何 L1 图都不得升级为 L4 标题。

## Protocol 6：停止条件

训练集有身份泄漏、数据许可缺失、预处理使用 Test 信息、图像形变出现不合理折叠或失控组织变化、神经网络连线数值校验失败、跨用户 MRI 信息泄漏、依赖输入/模型版本不匹配时——立即停止受影响实验，不准默默换参数获取好结果。

## Protocol 7：第一个科学问题（准备阶段）

选择正常脑室 ROI 而非肿瘤，测试自监督编码器是否对解剖上合理的局部体积变化产生跨个体可重复的内部响应，进一步测试候选神经元/通道的消融作用。形态扰动是否“解剖上合理”必须有外部 QC 支持；当前合成 phantom 的脑室变形不算此项科学结果。
