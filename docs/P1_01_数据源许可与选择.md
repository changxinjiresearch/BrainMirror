# BrainMirror P1.01 — 数据源资格、许可与来源记录

记录日期：2026-10-15。本文是 P1 的**来源审查**，不是数据下载/许可已获最终机构批准的证据。

## 首选：IXI（正常健康脑 MRI）

- 官网：https://brain-development.org/ixi-dataset/
- 官网说明：接近 600 名正常健康受试者；三家伦敦医院采集；包括 T1、T2、PD、MRA、DWI。
- 网页明确声明 CC BY-SA 3.0，并要求致谢数据来源。请保留来源和适用许可记录。许可原文：https://creativecommons.org/licenses/by-sa/3.0/
- BrainMirror P1 仅使用 IXI T1 作为**候选**数据，且仅能将来源所称 healthy 解释为“数据集级候选健康”，不是独立临床证明。
- 在下载或训练前，操作者要核实原始数据包的附带说明、授权及机构要求；`--accept-ixi-terms` 仅表明操作者已复核条款，不代表系统授予许可。
- 真实原始文件保存于私有持久存储，不能上传公开 GitHub 或演示网站。

## 备选 A：Calgary-Campinas (CC-359)

- 官方下载：https://www.ccdataset.com/download
- 官方说明健康脑 MRI 和银标准 brain masks；官方许可为 CC BY-ND 4.0。该许可含 NoDerivatives 限制，公开传播修改版本存在风险。
- 因此 P1 默认**不启用**本数据源，需要单独完成使用/衍生品合规审查。不要将其并入 IXI split。

## 备选 B：OASIS-1

- 官方：https://sites.wustl.edu/oasisbrains/home/oasis-1/
- 官方说明 416 名受试者，包括 100 名 60 岁以上很轻至中度 AD 受试者，**不是全健康数据集**。
- 数据使用受 Data Use Agreement 约束，见 https://sites.wustl.edu/oasisbrains/home/access/ 。
- P1 默认**不启用**；若后续使用，必须先取得适用数据授权，通过受试者级诊断元数据筛除 AD，禁止依赖扫描外观主观判断健康。

## 来源分层

| 数据源 | 当前决策 | 使用限制 | 状态 |
|---|---|---|---|
| IXI | 首选 | CC BY-SA 3.0；限 T1；私有原始文件 | 官网信息已核实；原始数据未取得 |
| CC-359 | 候补 | CC BY-ND 4.0；修改/分发须独立审查 | 不用于当前 P1 |
| OASIS-1 | 暂不使用 | 包含 AD；需要筛选和 DUA | 不用于当前 P1 |

## 数据版本及风险

1. 任何实际下载要记录官方源 URL、包名、取得日期、文件大小、SHA256、许可快照与去标识状态（**私有记录**）。
2. 文件名中的 IXI 病例编号是源内标识；不要把原始扫描路径、可识别名称、受试者编号或逐病例哈希公开提交 GitHub。
3. 官网描述的 healthy 并不能排除未记录异常；出现扫描异常时按 QC 和伦理要求处理，不将“健康”当临床金标准。
4. 不得自动从不受信任的镜像下载“替代 IXI”并混入正式数据。
5. 不得跨来源复用 split ID，未经独立相似性及重复主体审查不得合并数据集。
