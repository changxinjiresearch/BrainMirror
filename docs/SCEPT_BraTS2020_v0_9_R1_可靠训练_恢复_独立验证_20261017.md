# SCEPT v0.9-R1｜BraTS2020 可靠训练、双备份恢复与冻结测试协议

**日期：2026-10-17；工程状态：R1 代码实现与模拟故障恢复测试；真实 BraTS2020 训练与患者级结果尚未产生。**

## 实际依赖与边界

- `MONAI==1.5.1`，官方 `SwinUNETR`，4 通道 T1/T1ce/T2/FLAIR，3 个独立 sigmoid logit 分别对应 WT/TC/ET；权重文件必须来自实际训练，不接受合成测试权重冒充临床训练。
- 官方 BraTS2020 369 个带标签训练病例；冻结患者级 `258/55/56` train/validation/internal-test 划分。不能将 BraTS 官方无标签 validation 当成可计算本地 Dice 的测试集。
- 已经存在的 `scripts/scept_brats_v09.py prepare` 负责在可访问 369 个病例的执行环境中生成带 inventory digest 的冻结划分。**历史 369 例清单元数据不是 MRI 本身，不构成当前可以直接训练的证据。**
- R1 是科研训练基础设施，**没有实际触发 Kaggle 用户 GPU，未获得分割模型权重，也没有患者级 WT/TC/ET Dice**。这几个结论必须等真实计算完成才成立。

## 核心升级

新增 `brainmirror/scept/brats_r1_trainer.py` 与 `scripts/scept_brats_v09_r1.py`。

1. **精确断点续训**：快照包含模型权重、AdamW 优化器及动量、AMP GradScaler、Python global 与 sample RNG、NumPy global 与 sample RNG、Torch CPU/CUDA RNG、当前 step、最佳验证结果、验证历史与早停计数。恢复时恢复优化器设备；若种子、架构、数据清单、split、优化器、批次计划与超参数改变就拒绝继续。支持仅增加最终训练的 epochs。
2. **两槽原子快照**：使用 `slot0/slot1` 轮换；先写文件到临时文件，fsync，原子 rename；随后在另一个已经挂载的写入目录镜像相同字节，并 SHA-256 逐字节校验。manifest 只有在权重写入和哈希校验后才发布；若其中一槽损坏，优先加载另一槽有效备份并自动恢复本地副本。
3. **真实持久化要求**：`/kaggle/working` *不是*保证持久的容器外备份。CLI 必须显式传入 `--backup-dir` 与 `--confirm-persistent-backup`。这一确认只代表操作者已经事先挂载具有持久性的外部存储；代码**无法自行证明**远端存储确实永久可用。不要给两个普通 Kaggle 本地文件夹就误以为有独立备份。存储路径不可嵌套，不保存用户名 token；大尺寸模型 `.pt` 保留在访问受控的存储。对于断网/意外关机仍未 fsync 的当前优化步骤，可从最近一次有效快照**确定性重跑**，而不是声称零计算损失。
4. **验证集模型选择**：每次验证必须使用全部固定的 55 名验证患者（非 test），完整滑窗推理逐患者 WT/TC/ET Dice；三类的宏平均指标选择 `best`，并允许不达提升阈值早停。对当前配置，阶段性 checkpoint 与 `best` 两种产物分别持久化；训练过程从不读取测试标签用于调参。
5. **完整数据预检**：正式训练启动前，扫描全部 369 例的四模态和真实标签，检测文件缺失、NIfTI 几何不一致、非法标签和非有限数。已知 `BraTS20_Training_355` 使用 `_segm` 文件名的历史异常被明确支持。`--skip-full-preflight` 只用于工程调试，不可作为正式患者科学实验声明。
6. **可独立评估的最佳权重**：最佳权重格式与 v0.9 `load_attested_model` 完全一致，保存训练受试者、验证受试者、优化步数、MONAI 版本、数据指纹、最佳验证分数；从当前 best 槽提取 SHA-256，再用 v0.9 的 `evaluate` 对冻结 56 名测试患者一次性评估。**元数据自报不是训练来源的独立证明**，需要额外保存真实训练日志及 checkpoint SHA。
7. **审计范围**：GitHub 保存脚本、协议、聚合计数、日志哈希和结果 JSON。严禁将原始 MRI 或完整模型权重直接提交到公共仓库。

## 正式运行步骤（需真实 BraTS 数据、GPU、已写挂的外部独立持久存储）

```bash
# 执行环境：仓库根目录；仅示例，以下路径不是已确认挂载的存储。
pip install 'torch>=2.3,<3' 'monai==1.5.1' 'einops>=0.7,<1' 'nibabel>=5.3,<6' 'numpy>=1.26,<3'

# P0：冻结完整数据清单 + 258/55/56 患者级划分
PYTHONPATH=. python -m scripts.scept_brats_v09 prepare \
  --root /mounted/BraTS2020_TrainingData \
  --output /kaggle/working/scept_r1_split.json

# R1：确保 /mnt/external-persistent 已确认为真正持久的可写挂载。
PYTHONPATH=. python -m scripts.scept_brats_v09_r1 \
  --root /mounted/BraTS2020_TrainingData \
  --split /kaggle/working/scept_r1_split.json \
  --work-dir /kaggle/working/scept_r1 \
  --backup-dir /mnt/external-persistent/scept_r1 \
  --confirm-persistent-backup \
  --report /kaggle/working/scept_r1_training_report.json \
  --device cuda --epochs 30 --steps-per-epoch 120 \
  --checkpoint-every 20 --validate-every 1 --patch-size 96

# 若被中断：使用完全相同的全部参数，加上 --resume。
# 注意：原地重启若 Kaggle 环境已被销毁，需要先重新挂载原始数据、
# 原始冻结 split.json、以及同一持久 backup 目录。工作目录可自动从
# backup 的最晚 SHA 验证快照重建。
PYTHONPATH=. python -m scripts.scept_brats_v09_r1 \
  --root /mounted/BraTS2020_TrainingData \
  --split /kaggle/working/scept_r1_split.json \
  --work-dir /kaggle/working/scept_r1 \
  --backup-dir /mnt/external-persistent/scept_r1 \
  --confirm-persistent-backup \
  --report /kaggle/working/scept_r1_training_report.json \
  --device cuda --epochs 30 --steps-per-epoch 120 \
  --checkpoint-every 20 --validate-every 1 --patch-size 96 --resume
```

### 独立 56 例测试

R1 CLI **默认在正式训练完整结束或验证集早停后，自动触发一次性 56 例独立滑窗评估**；评估写入持久目录 `scept_r1_heldout_evaluation.json`，并对已有不同 checkpoint 的结果拒绝覆盖。`--skip-heldout-evaluation` 仅供工程调试，不能用于声称已独立验证。

如果自动评估因环境故障未能完成，可在训练与验证模型选择全部冻结后，读取备份中 `scept_r1_best_slot0.json` 或 `scept_r1_best_slot1.json`：按 `generation` 数值选择有 SHA256 校验且能加载的最高代。对应的 `.pt` 格式是 v0.9 标准 checkpoint。`<SHA>` 必须使用该代 manifest 的 `sha256` 字段；**不能猜测某个 best 槽**。

```bash
PYTHONPATH=. python -m scripts.scept_brats_v09 evaluate \
  --root /mounted/BraTS2020_TrainingData \
  --split /kaggle/working/scept_r1_split.json \
  --checkpoint /mnt/external-persistent/scept_r1/scept_r1_best_slotN.pt \
  --checkpoint-sha256 <MANIFEST_VERIFIED_SHA256> \
  --output /mnt/external-persistent/scept_r1_independent_heldout_eval.json \
  --device cuda --patch-size 96 --overlap 0.25
```

### 统计与执行门槛

- 必须在 56 个此前完全未参与训练和选模的独立患者上出具 WT/TC/ET 逐患者 Dice；项目中已有机制研究的最低启发式闸门为 WT≥0.65、TC≥0.45、ET≥0.35。此门槛不是临床合格证书或统计证明。
- 评估需要补充 HD95、空标注约定、患者级 Bootstrap 置信区间、失败病例审计和多随机种子；当前 v0.9 `evaluate` 主要提供 Dice。
- 上述断点测试使用微型卷积网络测试**精确恢复**；云端 MONAI 小模型仅是训练接口测试，绝不能替代真实 BraTS 训练。
- 当前无 Kaggle 连接和可写持久 backup 的自动控制权限；**不能宣称首次已训练真实模型已经取得**。
