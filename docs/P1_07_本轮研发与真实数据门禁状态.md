# P1 开发与实际数据门禁状态 · 2026-10-15

**结论：P1 工程扩展已提交候选；P1 全量真实 IXI 科学验收未完成。**

## 已实装的代码

1. 官方 IXI-T1 tar 显式下载、部分下载续传检测、安全目录解包、私有 SHA256/成员清单。由于官方未在本次流程提供已核对的公开 SHA，不能把单方计算 hash 称作官方独立验证。
2. `p1/intake.py`：独立于源仓库的逐扫描私有清单、实际 NIfTI 头检查、体素有限性及空图检查、精确文件 hash、HMAC 主体标识、草案 split。
3. `p1/preprocess.py`：真实 NIfTI 图像/独立掩膜空间对应、RAS、1.5mm 体素尺寸、画像三次插值与掩膜最近邻、固定 FOV 中心 crop/pad、脑组织保留率、脑 mask 内裁剪归一化，支持显式 N4 / 无 N4 策略，私有逐扫描可追溯哈希回执。
4. `p1/duplicates.py`：经过规范化的粗尺度图像相似性筛查，候选仅供独立审核，不能作为身份证明或自动判定；私有 token 化候选列表。
5. `p1/closeout.py`：缺失任何官方数据包独立验证、足够的完整来源队列、全量 QC、去重审阅、预处理与人工核准，即拒绝输出 `P1_PASS`。
6. CLI: `scripts/p1_acquire_ixi.py`、`scripts/p1_intake.py`、`scripts/p1_preprocess.py`、`scripts/p1_duplicates.py`、`scripts/p1_closeout.py`。
7. 合成 NIfTI 实际编解码测试 + 代码层工具测试，CI 独立验证环境安装 NiBabel 后运行。

## 未完成的真实科学验收

- 当前会话内没有可访问的 **全量真实 IXI-T1** 数据包及 private dataset mount；官网数据链接经公共浏览工具抓取返回 403，无法在此确认实际下载成功。
- 未在真实 IXI 卷积数据上读取原始扫描/审计每个受试者；没有独立合格脑 mask 或站点元数据完整复核。
- 真实 MRI 的预处理全量运行与视觉 QC、实质近重复对照和 split lock 不存在。
- `P1_PASS = FALSE`; `P2_TRAINING_AUTHORIZED = FALSE`。任何 synthetic test PASS 都不能改变这一事实。

## 下一步的唯一数据阻塞

在 Kaggle 或其他受限私有持久计算环境中实际挂载来自 IXI 官方原始数据，然后遵循 `P1_05_完整工程与数据验收.md` 跑一遍 P1 全量工作流；获取逐扫描和质量审核报告，人工复核异常，再出具数据锁定和独立审核收据。公共 GitHub 只能存储不含扫描标识的 QA 摘要以及经审核的代码/协议。
