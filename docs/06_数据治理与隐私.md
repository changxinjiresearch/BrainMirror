# BrainMirror — 数据治理与研究伦理最小规则

1. 数据所有权不由 GitHub 仓库的 public/private 决定。即便个人拥有下载权限，也不自动拥有公开再分发权限。
2. 在任何真实 MRI 下载/训练前，确认：官网来源、正式许可、署名要求、是否允许衍生模型、是否允许商业研究、是否允许公开图像和缓存。
3. 健康 MRI 也可能包含可识别面部结构，切勿假设“去姓名”就是完全匿名。应使用许可和伦理允许的 de-identification/defacing 工作流，并记录变换。
4. GitHub：仅源码、协议、配置、轻量非敏感结果、脱敏无患者级私人标签的统计、SHA256 manifest；大数据和 checkpoint 私有存储。
5. 开发环境：私有或受控计算，最小权限。线上必须分离每位用户上传数据，设置传输加密、鉴权、删除与保留期。
6. `synthetic_debug` 永远与真实数据训练、评估目录分离，不能混合训练后继续称“仅真实 MRI”。
7. 数据审计中的个体标识使用稳定但不暴露原始身份的编码；跨数据源匹配须在合规私有环境完成。
8. 运行日志不能输出完整患者路径、受试者姓名、MRI bytes 或上传原文件内容。
9. 涉及患者群体、诊断任务或临床结论时须另行处理研究伦理与许可证，不在 P0 验证中做医学结论。

**主要风险**：脑图像再识别、许可证不兼容、Train/Test 重复受试者、空间变换丢失 affine、演示误导、全局 state 导致跨用户泄露。每一类都有 P1/P5 专项门禁。
