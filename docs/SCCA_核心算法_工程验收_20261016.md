# BrainMirror / SCEPT: SCCA 跨层级干预解释引擎 (Engineering Alpha)

**状态：已实现可执行的候选边集合搜索与干预测试；尚未完成科学证据验证，不可宣称优于 Grad-CAM。**

## 1. 研究定义

对于四模态 3D 输入 `X`，在固定分割目标 `S_c,R` 和空间干预区域 `r` 上，首先计算输入参考变化 `D_r = S(X) − S(X'_r)`。将具体模型执行图中可单独干预的残差分支路径作为候选 *edge gates*，按梯度近似筛选，再用真实 forward intervention 测量：

- `N_C = S(X) − S(X; edge_C <- edge_C(X'_r))`：在原始输入下，将候选边集合替换为参考状态。
- `R_C = S(X'_r; edge_C <- edge_C(X)) − S(X'_r)`：在参考输入下，恢复候选边集合原始状态。

联合目标 `J(C) = ((D_r − R_C) / |D_r|)^2 + λ_sparse |C| + λ_off · OffTarget(C)/|D_r|`；`|D_r| < min_input_effect` 时不做回路推断。仅比较实测前向结果，不把梯度代理、Attention 权重当作因果证据。`direction_aligned` 单独报告，搜索优化不会把不一致强行改成通过。

## 2. 严格的路径/边语义

新增 TransformerBlock 内 `attn_to_residual` 与 `mlp_to_residual` **Identity edge gates**，每个 gate 的输出在当前 `forward` 中仅被一个残差相加运算消费。它们是特定且可执行的“分支→残差加法”连接的隔离干预点，不表示 token-token Attention 边、全神经元图或多层传播的唯一因果通路。

SCCA 自动搜索的是候选 **edge sets（边集合）**。多个单消费者边的联合干预可以揭示组合效应，却不等于证明存在一条按序贯穿所有边的完整因果回路。模型声明 `scca_edge_routes()` 元数据；当前仅校验命名模块/Identity 类型和字段，消费端唯一性依赖受审计的模型 `forward` 与数值测试，尚无通用的运行时证明。

兼容旧版 `attn`/`mlp`/`vib` **node patch**，但 **不允许** 将节点测试结果混入 edge-only SCCA 列表。

## 3. 详细执行顺序

1. 验证模型、ROI、配置、两种不同参考；固定确定性 VIB 推理（`sample=False`）。
2. 检查 Trace 与普通 Forward 结果的数值等价；`channel_mean` 作为候选发现参考，`local_blur` 只做后续未参与选择的参考复验。
3. 获取原始和参考输入下的真实 3D Transformer 各 Identity edge gates 激活。
4. 运行一阶近似 `q_e ≈ <grad_{A_e} S(X'_r), A_e(X)−A_e(X'_r)>`，按照 `|q_e|` 排序。
5. 在计算预算约束下对候选边集合运行真实的双向干预和 `off_target_change` 测量；使用 beam search 逐步扩展至 `max_circuit_size`。
6. 在第二种参考下对**冻结的最佳候选边集合**执行同样的前向干预，报告方向与恢复偏差（这是**同一病例跨参考验证**，不是独立患者验证）。
7. 机器可读 JSON 保存所有实测效应、筛选分数、搜索过的边集合、优化目标、缺失与矛盾状态。

## 4. 正确性基准和负控

- 已知合成因果依赖模型：选出信号路径，而非对输出权重严格为零的 decoy；破坏与恢复效应等于输入效应。
- 无输入干预效应：必须返回 `unresolved_low_input_effect`，不得输出“已验证回路”。
- 净零干预：恢复同一激活须严格不改变输出；错误形状、dtype、token mask 必须报错；异常退出后不得泄漏 Hook。
- 完整 Tensor-VIB：保持原始模型预测、参数和梯度不变；仅通过真实 forward 验证分支干预，不宣称由虚拟点线云获得结果。
- 两种不同输入参考的复验只作为敏感性检查；真实 BraTS 病例的影像合理性和独立患者验证**尚未完成**。

## 6. 本地运行 / GitHub CI

```bash
python -m pytest -q tests/test_scca.py tests/test_scept.py
python -m scripts.scca_smoke --output runs/scca_synthetic_smoke.json
```

`runs/scca_synthetic_smoke.json` 包含**人工合成的随机三维张量**计算结果，只能用于工程 QA，不是临床或模型泛化证据。之后应加入支持 windowed 3D attention 的高分辨率适配器，和严格预注册的独立患者外部评估。
