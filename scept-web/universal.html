04 / U7 XAI 实验插件与证据评价

一个声明式 JSON 插件可以指定模型指纹、真实数值目标、干预与调度、观测、XAI 方法和评价准则。导入新的 JSON 插件不需要修改 SCEPT 主程序。

可用目标：u7.target.tensor-element / tensor-mean；方法：u7.method.target-contrast / activation-response；评价：u7.eval.directional-shift / control-specificity / dose-monotonicity。外部可信脚本还可通过 U1 注册新的目标、方法、评价适配器。医学验证不能由插件声明自动获得。

先加载真实模型，再提供一个与模型匹配的实验插件。

审计文件 · 完整性指纹

U6 或 U7 运行成功后导出有 SHA-256 完整性校验的 U9 记录。审计会遮盖潜在的原始张量与掩膜索引，但推导出的统计结果和插件参数仍可能敏感，分享前应审阅。

重放会重新执行真实 ONNX 计算，不会复用审计中的旧张量充当新结果。模型、原始输入或配置不匹配必须拒绝；结果比较使用声明的浮点容差。浏览器关闭后需重新导入文件；不会创建付费计算资源。

科学与架构边界

已实现（U0–U9）：统一模型适配器注册、能力声明、参数类型/维度校验、模型来源哈希、真实 ONNX 结构和中间张量检查、浏览器 CPU 前向推理以及数值对比。

独立科学验证事项：临床级 MRI 空间变换、解释目标、任意未经插桩的隐藏状态干预、跨模型统一 Token 语义、因果解释与解释效果评价。

重要：导入新模型不等于自动获得可靠解释；模型必须可在当前 ONNX Runtime Web/WASM 执行。只对已在图元数据中声明的中间张量提供观测，不生成假值。
