04 / METHODS

Reproducibility protocol

Evidence types

L0 interface visualization; L1 real numeric tensor observations; L2 repeated statistical associations; L3 verified controlled internal interventions; L4 independently replicated mechanistic evidence.

Paired input perturbation alone qualifies as a measured response, not an internal causal intervention.

Adapter interface

Import an ONNX model exposing the required output probes. The graph input and output metadata are read at runtime. PyTorch checkpoints require conversion with supported export scripts before browser execution.

Transformer attention and intermediate activations must be exposed at export time. Model conversion does not require retraining.

Data governance

Raw MRI and patient data should not be committed into public GitHub. Browser model and data imports remain local; production research requires license checks, imaging preprocessing QC, and strict subject-level separation.

Scope

This implementation focuses on architecture-independent ONNX tensor inference and observation. MRI spatial editing, model-specific internal causal patching, and the future I-JEPA experiment are separate workstreams with explicit numerical acceptance tests.
